FaceNova

FaceNova is a real-time face attendance system built to work with cameras and RTSP CCTV streams. The system ensures attendance is marked only when a real human is present.

Key Features

  • Liveness detection
  • Blink verification
  • Head motion detection
  • RTSP CCTV support
  • Temporal trust window
  • Dual attendance logging

Technology

Python, OpenCV, Face Recognition Models, RTSP Streaming
